Requires [http-nu](https://github.com/cablehead/http-nu) >= 0.19.0

## Quick Start

```nushell
http-nu --datastar :3021 www/serve.nu
```

Visit http://localhost:3021

## Colours and fonts

`www/stellar.css` is generated by [Stellar](https://github.com/starfederation/stellar) from `www/stellar.config.json`, which holds the page's colours as named seeds (`night`, `terminal`, `blue`, `glow` and the kind colours) and its fonts. `www/site.css` names every colour from those ramps. To change a colour, change its seed and regenerate:

```nushell
do { cd www; stellar gen -i stellar.config.json; mv -f css/stellar.css stellar.css; rm -r css }
```
